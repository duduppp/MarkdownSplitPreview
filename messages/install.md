# MarkdownSplitPreview

Thanks for installing MarkdownSplitPreview.

This package renders Markdown with **pandoc**, which must be installed separately:

```bash
brew install pandoc        # macOS
sudo apt install pandoc    # Ubuntu / Debian
winget install --id JohnMacFarlane.Pandoc   # Windows
```

Open the command palette and run **Markdown Split: Preview (side by side)**.

No default key bindings are provided. See the README for suggested bindings.
